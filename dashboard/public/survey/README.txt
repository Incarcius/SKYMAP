Prototype survey imagery

area-01.jpg through area-04.jpg are four 1000x1000 crops generated from the supplied prototype orthophoto.
They are used only as demo survey inputs. The current images should be replaced with verified Indian rural
SVAMITVA drone/orthophoto patches before production deployment.

The dashboard keeps feature availability explicit per survey area. The current prototype crops do not provide
reliable visible water evidence, so the water layer is disabled for these four demo areas instead of displaying
water polygons from the source dataset as false positives. When real survey imagery is supplied, set
featureAvailability.water to true only for areas with validated water detections.
